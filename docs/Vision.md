# Decision OS

## 愿景

构建软件开发领域的 Decision Operating System。

让开发者从“管理代码”转变为“管理决策”。

## 核心理念

Software is accumulated decisions.

代码只是决策的投影。

## 用户画像

### 独立开发者
- 使用 Claude Code / OpenCode
- 维护中大型项目
- 经常需要阅读大量上下文

### Tech Lead
- 审核 Agent 输出
- 做架构决策
- 管理长期技术债

### 创业团队
- AI First 开发流程
- Agent 已承担大量编码工作

## 核心价值

### 传统 IDE

File → Code

### Decision OS

Requirement → Decision → Knowledge → Implementation

## 差异化

### Cursor
关注代码生成

### Claude Code
关注任务执行

### Devin
关注自主实施

### Decision OS
关注决策质量与知识管理

## 北极星指标

用户完成一次高质量决策所需时间。
