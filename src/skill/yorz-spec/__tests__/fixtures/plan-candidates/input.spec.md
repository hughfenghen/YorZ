# 最近访问入口

## 1. 背景

用户反馈每次打开应用都要在 spec 列表里翻找昨天碰过的几个 spec。希望首屏看到一个「最近访问」入口直接跳转。

## 2. 需求

- 新增「最近访问」入口，列出用户近期访问过的 spec
- 需要决定：入口挂在导航哪一层？数据来自本地还是服务端？最多保留多少条？是否提供清空按钮？

## 3. 现状分析

当前 GUI 主导航只有两个 tab：`Specs`、`Settings`。没有任何位置承载「最近访问」类的快捷入口。Spec 列表本身按 mtime 排序，并不区分「访问过 / 未访问过」，也没有任何客户端访问记录。
