# 最近访问入口

## 1. 背景

用户反馈每次打开应用都要在 spec 列表里翻找昨天碰过的几个 spec。希望首屏看到一个「最近访问」入口直接跳转。

## 2. 需求

- 新增「最近访问」入口，列出用户近期访问过的 spec
- 决策范围：挂载位置、数据来源、上限条数、清空策略

## 3. 现状分析

GUI 主导航当前只有 `Specs`、`Settings`；Spec 列表按 mtime 排序，没有访问记录。

## 4. 技术实现方案

- 在 `Specs` 列表上方插入「最近访问」区域，最多展示 10 条，按访问时间倒序。
- 访问记录写入浏览器 `localStorage`，key 为 `yorz:recent-specs`，存 spec id + 最后访问时间。
- 列表右侧提供「清空」按钮，弹确认对话框后清空 key。
