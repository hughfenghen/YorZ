# 阶段三：execute

理解文档内容，然后执行文档中的任务，每完成一个任务后勾选文档中的任务状态。

## 顺序执行

- 顺序执行 `## 任务清单` 中未完成项（`- [ ]`）。
- 执行中若发现新增/扩展需求或新增 bug，立即停止继续勾选，切回 `plan` 并记录重开原因（详见 [全局硬约束](./rewrite-rules.md) 的变更重开规则）。

## 每完成一项后立刻

- 将该项从 `- [ ]` 改为 `- [x]`。
- 在 `## 执行记录` 增加一条结果（改动点、验证方式、阻塞项若有）。

## 默认执行验证

- 若仓库存在可用测试/构建命令，默认执行并记录结果。
- 若当前环境无法执行验证，记录原因并保留相关任务未完成或追加阻塞记录。

## 追加任务 `[open] → [fixed]` 状态机

若本轮起因是 `## 追加任务` 中的 `[open]` 条目：

- 每完成一个追加项，必须把对应条目的状态标记从 `[open]` 改为 `[fixed]`（位置和正文保留不变）。
- 在 `## 执行记录` 追加一条结果，链接到该条目的描述首行。
- 已 `[fixed]` 的条目保留在 md 中作为历史，**不删除**。
